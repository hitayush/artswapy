Thread interactions

Six micro-interactions for ArtSwapy, each taken from the craft the practice works in: stitching, setting type, folding paper, stamping. Hover, tap and tab through them.

There is no magnet and no left-to-right colour fill. Every curve is a cubic-bezier, and every exit is quicker than its entrance.

Needle pass

The primary button. A needle runs through the label, and each letter re-sets the moment it's crossed. The arrow gets pulled through behind it. The orange stays orange, so the button keeps its colour and gains motion instead of a fill.

Trigger
Pointer enter, once per hover
Needle
440ms, ease-in-out (0.77, 0, 0.175, 1)
Letters
260ms each, ease-out, timed to the needle
Press
Tug: 1px down, scale 0.97, 140ms in / 200ms out

Taut thread

Links. On hover a slack thread appears under the word and pulls tight, the way thread does when you draw a stitch closed. The current page keeps its thread taut. Links inside a sentence carry a quiet underline at rest, and the thread replaces it.

Pull
Sag 9px → 0 over 320ms, ease-out
Appear
120ms opacity; exit 160ms
Touch
Same pull on press

Unzip

Work rows. The row's band opens outward from exactly where your pointer came in, like a seam unpicked from that stitch. When you leave, it closes back toward the point you left from. The preview cross-fades through a 2px blur so the two pictures read as one change. Tabbing through moves instantly, because keyboard moves are never animated.

Open
300ms, ease-out, from the pointer's x
Close
180ms toward the exit point
Preview
240ms opacity + blur bridge

Shared rules

Every control tugs on press (1px down, scale 0.97). Hover effects only run on a real pointer. Touch gets the same motion on press instead. With reduced motion turned on, colour and opacity changes stay and all travel is removed.
