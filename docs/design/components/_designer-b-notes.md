# Designer B notes: issues in DESIGN.md and the direction sheet

Specs not diverging silently; each item below names where I deviated or need a decision.

1. **Five type steps cannot serve the direction's sizes (blocking for DESIGN.md §2).** The direction uses 6.5vw (intro heading), 5.4vw (Work names) and 6vw (contact rows); none maps onto Monument, Poster, Heading, Body or Small. Mapping all to Poster (130px) makes five sections shout, and at 390 the 56px Poster floor is too wide for "Communications", "Common Ground" and "hello@artswapy.com". **Proposal: add one token `--step-row: clamp(36px, 6.4vw, 92px)`** (leading 1.0, tracking -0.03em) used by Intro heading, Work names, Contact rows. This stays within "at most 2 typefaces" but is a sixth size; needs sign-off. The ≤3 sizes rule of the direction ("two sizes do nearly all the work") still holds.
2. **Poster floor at 390 overflows process stage names.** "Communications" at 56px ≈ 400px > 358px available. Process and About use `min(var(--step-poster), 11.5vw)` on phones. If you prefer a token: `--step-poster-m`.
3. **Accent conflict (services hover).** Direction: hover swaps ink to accent. DESIGN.md: accent = action + thread only. Resolved in favour of DESIGN.md: hover draws the thread, ink never changes colour (also orange display text is ≈ 3:1 on `--bg`). See services-poster.md.
4. **Direction fades inactive Work names to 35% opacity.** Already overridden by the sheet's own "Adjusted for this page" and DESIGN.md §5. Active state is the `--surface` band, the shift, the thread and the preview.
5. **DESIGN.md §3 "background steps to --surface" animates colour.** House rule says animate only transform/opacity/clip-path. Specs implement the step as a `::before` pseudo-element wiped with clip-path, which satisfies both. Recommend DESIGN.md say so.
6. **`html.js` gate hole.** The direction recipe hides content under `.js`, set by an inline script. If the bundle fails after that, content stays hidden. Specs gate on `html.reveal-ready`, added after React mounts, with a 4s safety timer (section-entrance.md). Also fixes: roots already scrolled past on load/anchor jump stay hidden under the plain recipe.
7. **Direction's contact blueprint has five address rows; ArtSwapy has no street, hours or phone.** Specs use four rows (email, location, availability, greeting). The phone rule "greeting row becomes an accent band" conflicts with DESIGN.md's accent rule; DESIGN.md wins: band stays tonal, only the round button is orange.
8. **About blueprint assumes up to six portraits and a `difference` title.** Adapted for one founder: shorter pin (≈190svh), title in solid ink, portrait passes in front, bio tagged placeholder. A second portrait crop is needed (hero already uses the only one).
9. **Intro captions are specified as 150px-wide two-line captions at 13px.** The existing copy (`intro.lead`, `intro.body`) is 20+ words each. Captions are widened to ~34ch at 16px and placed on columns 1 and 5; 47% of the panorama is visible at the fold (blueprint asks 55–60%). Shorten the copy if the picture needs to show more.
10. **Services has no price/time "fact" to show.** None is confirmed and none is invented; `fact` is a short deliverables phrase. Service name "Packaging & Communications" does not fit one poster line; shortened to four one-word names (and "Experiences").
11. **DESIGN.md §3 index row grammar says the "short thread follows the cursor" for Work and Services rows alike.** Specs give it to Work only (it needs room along the baseline); Services uses the draw-on thread under the name. Two threads on one screen would break "one thread per screen".
12. **Header over the pinned inverse field** needs a `data-on-inverse` state (Header is designer A's). Flag so header colours do not become ink-on-black while Process is pinned.
13. **Pinned layers on short viewports.** `100svh` pins at `max-height: 540px` leave no room; process and about collapse to normal flow there as well as under reduced motion and no JS. Not mentioned in DESIGN.md §4.5.
14. **Phone expand on Services snaps height** (layout animation is banned). Accepted trade-off, documented in its spec.
15. **Copy that must move into content.js:** `intro.heading`, `intro.panorama`, `work.heading`, `projects[].placeholder/preview`, `services[].poster/fact`, `process` block, `about.heading/role/portrait`, `contact.greeting/location/availability/mailto`.
